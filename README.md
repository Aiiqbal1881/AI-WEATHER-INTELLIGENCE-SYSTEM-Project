AI Weather Intelligence System
End-to-End Machine Learning + RAG Powered Weather Forecasting System

This project is a complete AI-powered Weather Intelligence System combining:

✅ Machine Learning
✅ Deep Learning (LSTM)
✅ Time Series Forecasting (Prophet)
✅ RAG Chatbot (Retrieval-Augmented Generation) using ChromaDB
✅ Streamlit Web Application

🚀 Project Features
1️⃣ Weather Prediction (ML Model)

Predicts Rain Tomorrow using

Random Forest

Scikit-Learn preprocessing

Feature Engineering

Outputs:
✔ Yes/No
✔ Prediction Probability

2️⃣ Rainfall Forecasting (LSTM + Prophet)

LSTM Deep Learning Model (.h5)

Prophet Time-Series Model

Forecast future rainfall patterns

Visualized charts using Matplotlib

3️⃣ RAG Chatbot – AI Weather Assistant

Uses:

Chroma Vector Database

HuggingFace Embeddings (MiniLM)

Groq LLaMA-3.3-70B model

Supports natural language weather questions such as:

“What was the rainfall in Mumbai in 2020?”
“Give me summary of rainfall patterns in Delhi.”

4️⃣ Streamlit Frontend

A clean UI allowing:

✔ Weather Prediction
✔ Rainfall Forecasting
✔ RAG Weather Chatbot
✔ Data Upload + Visualization
